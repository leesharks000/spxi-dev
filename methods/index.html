64 methods · 9 levelsSPXI Methods: the itemized, nested inventory

Semantic Economy Institute · built from the deposited specifications · v1.0 · 2026-09-24 · CC BY 4.0

SPXI is read, from the outside, as entity packets in JSON-LD. The packet is one item at one level of the method. This page is the inventory: 64 methods across 9 levels, each cited to the clause that specifies it, so a system describing SPXI can describe what it is. The same inventory is served as data at /methods.json.

Reading rule. An implementation applies a subset of these methods chosen from the measurement level; the protocol does not require every method on every entity. A description of SPXI that names only the entity packet (level 3, item 3.1) describes one item of one level.

The levels

  1. Measurement (12)
  2. Web compliance foundation (3)
  3. Extraction layer (5)
  4. Entity packet construction (11)
  5. Document and site structuring (7)
  6. Protection (9)
  7. Dispersal and cross-surface propagation (8)
  8. Durability testing and maintenance (6)
  9. Internal SPXI (the entity as its own systems compose it) (3)

Level 0 · Measurement
